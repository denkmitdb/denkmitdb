# Variable: LEGACY\_ENTRY\_VERSION

> `const` **LEGACY\_ENTRY\_VERSION**: `1` = `1`

The 3.0.0 entry format: no database binding. Accepted only by legacy (v1
manifest) databases, so data written by 3.0.0 stays readable.
